# WealthWise
WealthWise is a self-hosted personal finance and wealth-tracking dashboard built with Python and Django. It aggregates data from bank accounts, stock portfolios, and commodities to provide a unified view of your total net worth, asset allocation, and financial performance.

## Features
1. Comprehensive Dashboard
- Total Equity Tracking: Real-time calculation of total net worth across banks, stocks, cash, and commodities.
- Cash Flow Analytics: Visual breakdowns of monthly and yearly income vs expenses.
- Stock Performance: Instant insights into realized gains/losses, dividends received, and current open portfolio performance.
- Asset Allocation: An overall view of assets categorized by cash, commodities, bank accounts, and stocks.

2. Banking Ledger
- Account Management: Track multiple bank accounts and their respective live balances.
- Transaction Logging: Detailed historical ledger of incoming and outgoing transactions.

3. Stock Portfolio Manager
- Position Tracking: Monitor current stock holdings, average purchase prices, quantities, and current market value.
- Transaction Ledger: Log transaction execution history.
- Friction Cost Accounting: Track administrative fees and taxes per trade to calculate true realized performance.

## Tech Stack
Backend Framework: Python 3.9 / Django 4.2
Database: PostgreSQL
Frontend: Django Templates, TailwindCSS, Bootstrap
